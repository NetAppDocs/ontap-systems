= Review requirements before replacing the controller in an ASA A250 system
:icons: font
:imagesdir: ../media/

[.lead]
Before replacing the controller in your ASA A250 storage system, ensure you meet the necessary requirements for a successful replacement. This includes verifying all other components in the system are functioning properly, verifying that you have the correct replacement controller, and saving the controller's console output to a text log file.

include::../_include/250_controller-replace-requirements.adoc[]

.What's next?

After you've reviewed the requirements to replace the impaired controller, you need to link:controller-replace-shutdown.html[shut down the impaired controller].

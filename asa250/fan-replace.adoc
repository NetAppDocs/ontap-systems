= Replace a fan in an ASA A250 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace a failed fan module in an ASA A250 system by shutting down the impaired controller, opening the controller module, and installing the replacement fan. This procedure keeps controller components cooled and prevents thermal-related system faults.

= Hot-swap a power supply unit in an ASA A250 system
:icons: font
:imagesdir: ../media/

[.lead]
Hot-swap a failed power supply unit (PSU) in an ASA A250 system without shutting down the controller. The PSUs are redundant and auto-ranging, so replacing a failed PSU with a matching type keeps the system running without interruption.

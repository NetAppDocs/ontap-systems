= Replace the NVMEM battery in an ASA A250 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace a failed NVMEM battery in an ASA A250 system by shutting down the impaired controller, opening the controller module, and installing the replacement battery. This procedure protects cached write data from loss due to a degraded battery.

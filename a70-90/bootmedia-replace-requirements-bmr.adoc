= Requirements for automated boot media recovery - AFF A70 and AFF A90
:icons: font
:imagesdir: ../media/

[.lead]
Review the requirements before replacing the boot media in your AFF A70 or AFF A90 storage system, including cluster port functionality, key manager configuration, and ONTAP version compatibility.

The automated boot media recovery process requires ONTAP 9.17.1 or later. If your storage system runs an earlier version of ONTAP, use the link:bootmedia-replace-workflow.html[manual boot recovery procedure].

include::../_include/bootmedia_replace_requirements_cluster_bmr.adoc[]

.What's next

After you've reviewed the boot media requirements, you link:bootmedia-shutdown-bmr.html[shut down the controller].

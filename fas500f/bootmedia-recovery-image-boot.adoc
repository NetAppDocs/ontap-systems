= Manual boot media recovery from a USB drive - FAS500f
:icons: font
:imagesdir: ../media/

[.lead]
After installing the new boot media device in your FAS500f system, you can boot the recovery image from a USB drive and restore the configuration from the partner node.

If your storage system is running ONTAP 9.18.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure]. If your system is running an earlier version of ONTAP, you must use the manual boot recovery procedure.

.What's next?
After booting the recovery image, you need to link:bootmedia-encryption-restore.html[restore encryption on the boot media].

= Give back the controller in your FAS500f system to resume normal operations
:icons: font
:imagesdir: ../media/

[.lead]
Return control of storage resources to the replacement controller so your FAS500f system can resume normal operation. After you've restored and verified the system configuration, recable the system and reassign disks.

include::../_include/250_controller-replace-recable-reassign-disks.adoc[]

.What's next?
After you've recabled the system and reassigned disks, you need to link:controller-replace-restore-system-rma.html[complete the controller replacement].

// Remove the controller module - AFF A800

.Steps

. If you are not already grounded, properly ground yourself.
+

. Ensure that all drives in the chassis are firmly seated against the midplane by using your thumbs to push each drive until you feel a positive stop.
+
video::2c46e4af-2c21-4f12-b065-b38b003d0ea2[panopto, title="Video - Confirm drive seating"]
+
image::../media/drw_a800_drive_seated_IEOPS-960.svg[Seat the drives]
+
. Check the controller drives based on the system status:

.. On the healthy controller, check that any active RAID group is in a degraded state and/or failed state:

+
[source,cli]
----
storage aggregate show -raidstatus !*normal*
----

.. Check for missing drive issues for both the file system or spare drives:

+
[source,cli]
----
event log show -severity * -node * -message-name *disk.missing*
----

+
.. Continue if any disk failures or missing drive events happened:

+
[options="header" cols="1,2"]
|===
a|If... | Then...
a| 
Any events related to a drive or drives gone missing happened...
a|
. Collect the AutoSupport data from both controllers.

+
[source,cli]
----
system node autosupport invoke -node * -type all -message '<message_name>'
----


. Remove the drive and reinsert it after 70 seconds, following the instructions in the link:https://docs.netapp.com/us-en/ontap-systems/fru-reference/drive-fru-links.html[Drive replacement procedures by platform family].

+
NOTE: If the disk or any of its partitions are part of an aggregate and not a spare, do not proceed. Contact NetApp Support for further assistance.

.. Halt the impaired controller to the LOADER prompt.

+
[source,cli]
----
halt
----

a|No events happened...
a| Go to the next step.
|===

+
.. Run the `system node run local disk show`  command and save the output:

+
[source,cli]
----
system node run -node local -c disk show -w
----

+
.. Boot the offline controller into maintenance mode from the LOADER prompt.

+
[source,cli]
----
boot_ontap maint
----

+
.. Get the output from the `disk show`  command:

+
[source,cli]
----
disk show -w
----

+
.. Compare the output with the healthy controller and recover any impacted drives.

+
NOTE: If the drives are file system drives, do not proceed. Contact NetApp Support for further assistance.

.. Halt the impaired controller to the LOADER prompt.

+
[source,cli]
----
halt
----

. Remove the power cable retainers, then unplug the cables from the power supplies.

. Loosen the hook and loop strap on the cable management device. Unplug the system cables and SFP/QSFP modules (if needed) from the controller module. Note each cable's location.
+
Leave the cables in the cable management device so that when you reinstall the cable management device, the cables are organized.

. Remove the cable management device from the controller module and set it aside.
. Press down on both of the locking latches, and then rotate both latches downward at the same time.
+
The controller module moves slightly out of the chassis.
+
image::../media/drw_a800_pcm_remove.png[Removing the controller module]
+

[cols="1,4"]
|===
a|
image:../media/icon_round_1.png[Callout number 1]
a|
Locking latch
a|
image:../media/icon_round_2.png[Callout number 2]
a|
Locking pin
|===

. Slide the controller module out of the chassis and place it on a stable, flat surface.
+
Support the bottom of the controller module while sliding it out of the chassis.

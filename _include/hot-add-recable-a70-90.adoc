When you hot-add a second shelf to an A70 or A90 HA pair, you need to recable the first shelf across the RoCE-capable I/O modules in slot 11 and slot 8 on each controller. 

The procedure assumes the existing shelf is cabled to a RoCE-capable I/O module in slot 11 on each controller.

.Steps

. Recable the first shelf across the RoCE-capable I/O modules in slot 11 and slot 8 on each controller.
+
.. On controller A, move the cable from slot 11 port b (e11b) to slot 8 port b (e8b).
.. Repeat the same cable move on controller B.

. Verify that the recabled shelf is cabled correctly using https://mysupport.netapp.com/site/tools/tool-eula/activeiq-configadvisor[Active IQ Config Advisor^].
+
If any cabling errors are generated, follow the corrective actions provided.

When you hot-add a second shelf to an A30, C30, A50, or C60 HA pair, you need to recable the first shelf across the RoCE-capable I/O modules in slot 3 and slot 1 on each controller. 

The procedure assumes the existing shelf is cabled to a RoCE-capable I/O module in slot 3 on each controller.

.Steps

. Recable the first shelf across the RoCE-capable I/O modules in slot 3 and slot 1 on each controller.
+
.. On controller A, move the cable from slot 3 port b (e3b) to slot 1 port b (e1b).
.. Repeat the same cable move on controller B.

. Verify that the recabled shelf is cabled correctly using https://mysupport.netapp.com/site/tools/tool-eula/activeiq-configadvisor[Active IQ Config Advisor^].
+
If any cabling errors are generated, follow the corrective actions provided.

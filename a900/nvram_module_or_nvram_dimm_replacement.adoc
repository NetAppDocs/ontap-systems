= Replace the NVRAM module or NVRAM DIMMs in an AFF A900 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace the NVRAM module or NVRAM DIMMs in your AFF A900 system when the module fails or a DIMM becomes faulty. The replacement process involves removing the NVRAM module from the chassis, replacing the failed component, and reinstalling the module.

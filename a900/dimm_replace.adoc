= Replace a DIMM in an AFF A900 system to fix memory errors
:icons: font
:imagesdir: ../media/

[.lead]
Replace a DIMM in your AFF A900 system when the storage system encounters excessive correctable (CECC) or uncorrectable memory errors. Such errors can prevent the storage system from booting ONTAP.

= Replace the boot media in an AFF A900 system during the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
The boot media in your AFF A900 system stores essential firmware and configuration data. The replacement process involves removing the controller module, removing the impaired boot media, installing the replacement boot media, and then transferring the ONTAP image to the replacement boot media using a USB flash drive.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure]. If your system is running an earlier version of ONTAP, you must use the manual boot recovery procedure.

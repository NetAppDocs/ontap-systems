= Replace the chassis in an AFF A900 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace the chassis of your AFF A900 system when a hardware failure requires it. The replacement process involves removing the power supplies, fans, controller modules, and I/O modules from the impaired chassis and installing them in the replacement chassis.

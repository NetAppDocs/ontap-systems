= Replace the DCPM module containing the NVRAM11 battery in an AFF A900 system
:icons: font
:imagesdir: ../media/

[.lead]
Hot-swap the destage controller power module (DCPM) in your AFF A900 system when it fails. The DCPM contains the NVRAM11 battery and must be replaced within five minutes of removal to prevent loss of data protection.

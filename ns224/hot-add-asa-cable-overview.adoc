= Cable an NS224 shelf to your ASA system
:icons: font
:imagesdir: ../media/

[.lead]
Cable your NS224 shelf to your ASA system to provide dual-path connectivity that ensures storage redundancy and high availability for the HA pair.

== Cabling overview for ASA systems

Cabling differs by ASA platform model because each system has unique port assignments and I/O module configurations.

During the hot-add cabling procedure, you connect each NS224 shelf to both controllers in the HA pair:

* Each shelf NSM module connects to a dedicated storage port on each controller, creating two paths per shelf (one through NSM A, one through NSM B).
* This dual-path configuration provides storage redundancy and ensures continued data access if a single path fails.
* Cables connect from the shelf NSM e0a/e0b ports (NSM100) or e1a/e1b ports (NSM100B) to RoCE-capable storage ports on the controllers.

== Additional resources

Your hardware system may be compatible with both NS224 shelves with NSM100 modules and NS224 shelves with NSM100B modules. For comprehensive port names and configuration details, see https://hwu.netapp.com[NetApp Hardware Universe^].

= Cable an NS224 shelf to an ASA A20 system
:icons: font
:imagesdir: ../media/

[.lead]
Cable your NS224 shelf to your ASA A20 system so that each shelf has two connections to each controller in the HA pair.

You can hot-add a maximum of one NS224 shelf to an ASA A20 HA pair when additional storage (to the internal shelf) is needed.

include::../_include/cable-20-hot-add-shelf.adoc[]



.What's next

If you disabled automatic drive assignment as part of the preparation for this procedure, you need to manually assign drive ownership and then reenable automatic drive assignment, if needed. Go to link:hot-add-asa-complete.html[Complete the hot-add].

Otherwise, you are done with the hot-add shelf procedure.

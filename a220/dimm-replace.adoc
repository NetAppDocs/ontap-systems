= Replace a DIMM in an AFF A220 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace a DIMM in your AFF A220 system when the storage system encounters excessive correctable ECC errors or an uncorrectable ECC error, which is typically caused by a single DIMM failure.

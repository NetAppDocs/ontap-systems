= Replace the controller in an AFF A220 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace the controller in your AFF A220 system by removing the impaired controller, moving FRU components to the replacement controller module, installing it in the chassis, and booting to Maintenance mode.

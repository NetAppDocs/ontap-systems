= Switch back aggregates in a two-node MetroCluster configuration - FAS8200
:icons: font
:imagesdir: ../media/

[.lead]
Perform the MetroCluster switchback operation on a FAS8200 system after completing boot media replacement in a two-node MetroCluster configuration. This procedure includes verifying node and storage virtual machine (SVM) states, executing the switchback command, and confirming that the configuration returns to normal operating state with sync-source SVMs serving data from local disk pools.

The FAS8200 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

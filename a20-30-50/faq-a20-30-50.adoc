This FAQ answers common questions about the AFF A20, AFF A30, and AFF A50 storage systems. It focuses on installation, maintenance, system specifications, and component replacement procedures that are useful when setting up, operating, and maintaining these storage platforms.

== System specifications and differences

.What are the key differences between the AFF A20, AFF A30, and AFF A50 models?

The primary differences are memory capacity and scaleout limits. The AFF A20 and A30 have 128 GB of memory, while the A50 has 256 GB. For NAS configurations, the A20 supports up to 3 HA pairs, the A30 up to 4 HA pairs, and the A50 up to 12 HA pairs. All three models share the same 2U chassis form factor with 24 drive slots and support up to 4.0 PB raw capacity per HA pair.

.What storage protocols are supported on the AFF A20, A30, and A50?

All three models support the following protocols: CIFS, FC, iSCSI, NFS (v3, v4.0, v4.1, v4.2), NVMe/FC, NVMe/TCP, S3, S3 with NAS, and SMB (2.0, 2.1, 2.x, 3.0, 3.1, 3.1.1).

.How many PCIe expansion slots are available on these systems?

All three models (AFF A20, A30, and A50) have 8 PCIe expansion slots available for I/O modules.

.What is the difference between automated and manual boot media recovery?

Automated boot media recovery is supported in ONTAP 9.17.1 and later, where the system automatically identifies and selects the appropriate boot menu option and retrieves the boot image from the partner node. Manual boot media recovery is required for earlier ONTAP versions and involves using a USB drive with a downloaded ONTAP recovery image to reinstall ONTAP on the replacement boot media.

.What are the environmental specifications for these systems?

Operating temperature ranges from 10°C to 35°C (50°F to 95°F) at up to 3048m (10,000 ft) elevation with 8% to 80% relative humidity (noncondensing). All three models have a 2U height and weigh 60.7 lb (27.5 kg). Non-operating temperature ranges from -40°C to 70°C (-40°F to 158°F) up to 12192m (40,000 ft) with 10% to 95% relative humidity (noncondensing) in the original container.

.What management ports are available?

All three models have the following management ports:

* 2 Ethernet 1 Gbps ports
* 4 RS-232 115 Kbps ports
* 2 USB 600 Mbps ports

.What are the scaleout maximums for SAN configurations?

For SAN configurations, the AFF A20 supports up to 3 HA pairs with 12.1 PB raw capacity, the AFF A30 supports up to 4 HA pairs with 16.2 PB raw capacity, and the AFF A50 supports up to 6 HA pairs with 24.2 PB raw capacity.

== Installation and setup

.How do I install the AFF A20, A30, or A50 storage system?

The installation workflow involves reviewing installation requirements, preparing the site, installing the rail kits and hardware in the rack, cabling the cluster/HA connections, host network connections, management network connections, and shelf connections, powering on the shelves and controllers, and then setting up the ONTAP cluster.

== Boot media recovery

.What do I need to perform automated boot media recovery?

You need the correct replacement boot media and a working e0M (wrench) management port on the impaired controller. You should also determine whether Onboard Key Manager (OKM) or External Key Manager (EKM) is enabled. This process is only supported in ONTAP 9.17.1 and later.

== Hardware maintenance and component replacement

.What is the minimum ONTAP version required for the AFF A20, A30, and A50?

The minimum ONTAP version required is ONTAP 9.16.1RC1 for all three models (AFF A20, A30, and A50).

.What are the cluster and HA interconnect requirements for these systems?

The cluster interconnect traffic and HA traffic share the same physical ports on the I/O modules. For the AFF A20, these are 10/25 GbE ports on the I/O module in slot 4. For the AFF A30 and A50, these can be 40/100 GbE ports on I/O modules in slots 2 and 4 (for two-module configurations) or slot 4 only (for one-module configurations). Both switchless and switched cluster configurations are supported.

.Can I hot-swap components in my AFF A20, A30, or A50 system?

You can hot-swap power supplies without taking down the system. For I/O modules, hot-swapping is supported in ONTAP 9.17.1 and later without requiring a manual takeover. Other components such as DIMMs, fans, NV batteries, and RTC batteries require shutting down the controller before replacement.

.When should I use the I/O module hot-swap procedure?

Use the hot-swap procedure when your storage system is running ONTAP 9.17.1 or later and you need to replace a failed Ethernet I/O module with an equivalent module. Hot-swapping allows you to restore the system without performing a manual takeover. If you need to upgrade to a different I/O module type or your system is on an earlier ONTAP version, use the replace procedure which requires a manual takeover.

.Can I add I/O modules to my system?

Yes, you can add I/O modules to enhance network connectivity and expand your system's ability to handle data traffic. You can add I/O modules when there are slots available or when all slots are fully populated. The process involves shutting down one controller, adding the I/O module, rebooting, then repeating the process for the other controller.

.Can I hot-swap a drive?

Yes, you can hot-swap drives when they fail or require an upgrade. The replacement process involves identifying the faulty drive, safely removing it, and installing a new drive to ensure continued data access and system performance without shutting down the system.

.What is the System Management module?

The System Management module provides the interface between the controller and a console or laptop for controller or system maintenance purposes. It contains the boot media and stores the system serial number (SSN).

.What is an I/O module?

The I/O module (Input/Output module) is a hardware component that acts as an intermediary between the controller and various devices or systems that need to exchange data with the controller. You can add, hot-swap, or replace I/O modules to enhance network connectivity, improve redundancy, and support higher performance or additional features.

== High availability and management

.What high availability features do these systems support?

All three models support the following high availability features:

* Ethernet-based baseboard management controller (BMC) and ONTAP management interface
* Redundant hot-swappable controllers
* Redundant hot-swappable power supplies
* SAS in-band management over SAS connections for external shelves

== Network and cabling

.How do I cable for a switchless cluster configuration?

For switchless clusters, you connect the controllers directly to each other. For AFF A30 or A50 with two 100 GbE I/O modules, cable controller A port e2a to controller B port e2a, and port e4a to controller B port e4a. With one 100 GbE I/O module, cable port e4a to e4a and port e4b to e4b. For AFF A20 with one 25 GbE I/O module, cable port e4a to e4a and port e4b to e4b. Ports e2b and e4b (for two-module configs) are available for host network connectivity.

.How do I cable for a switched cluster configuration?

For switched clusters, you connect the controllers to cluster network switches. For AFF A30 or A50 with two 100 GbE I/O modules, cable controller A port e4a and controller B port e4a to switch A, and controller A port e2a and controller B port e2a to switch B. With one 100 GbE I/O module, cable controller A port e4a and controller B port e4a to switch A, and controller A port e4b and controller B port e4b to switch B. Similar patterns apply for AFF A20 with 25 GbE modules.

= Review the requirements for replacing a controller in an AFF A1K system
:icons: font
:imagesdir: ../media/

[.lead]
Before replacing the controller in your AFF A1K system, verify you meet the necessary requirements for a successful replacement. This includes verifying all other components in the system are functioning properly, verifying that you have the correct replacement controller, and saving the controller's console output to a text log file.

= Replace the boot media in your AFF A1K system using the automated boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
The boot media in your AFF A1K system stores essential firmware and configuration data. Replacing it involves removing the System Management module, removing the impaired boot media, installing the replacement boot media, and reinstalling the module.

The automated boot media recovery process is supported only in ONTAP 9.17.1 and later. If your storage system is running an earlier version of ONTAP, use the link:bootmedia-replace-workflow.html[manual boot recovery procedure].

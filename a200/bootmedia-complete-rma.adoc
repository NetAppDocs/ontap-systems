= Return the failed AFF A200 boot media to NetApp
:icons: font
:imagesdir: ../media/

[.lead]
Return the failed AFF A200 boot media to NetApp after replacing the boot media, as described in the RMA instructions shipped with the kit. See the https://mysupport.netapp.com/site/info/rma[Part Return and Replacements] page for further information.

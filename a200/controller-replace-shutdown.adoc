= Shut down the impaired controller in an AFF A200 system before replacement
:icons: font
:imagesdir: ../media/

[.lead]
Shut down the impaired controller in your AFF A200 system before replacement by taking it over and halting it to the LOADER prompt.

include::../_include/shutdown_no_mcc.adoc[]

. If the system has only one controller module in the chassis, turn off the power supplies, and then unplug the impaired controller's power cords from the power source.

= Check encryption support on the boot media in an AFF A200 system
:icons: font
:imagesdir: ../media/

[.lead]
To ensure data security on your storage system, you need to verify the encryption key support and status on your boot media. Check if your ONTAP version supports NetApp Volume Encryption (NVE), and before you shut down the controller check if the key manager is active. The AFF A200 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

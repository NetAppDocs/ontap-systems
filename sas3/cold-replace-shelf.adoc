= Cold-replace a DS212C, DS224C, or DS460C shelf
:icons: font
:imagesdir: ../media/

[.lead]
You need to perform a cold shelf replacement when replacing a drive shelf in a production system that has disks in use. This is a disruptive procedure that requires you to halt the controllers in your HA pair.

This procedure applies to shelves with IOM12, IOM12B, or IOM12C modules.

Use the NetApp Knowledge Base article https://kb.netapp.com/onprem/ontap/hardware/How_to_replace_a_shelf_chassis_using_a_cold_shelf_removal_procedure[How to replace a shelf chassis using a cold shelf removal procedure].

= Restore encryption on the boot media in a FAS2820 system after the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
After you replace the boot media in your FAS2820 system, restore encryption on the new device to maintain data security and return the system to its original configuration.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure]. If your system is running an earlier version of ONTAP, you must use the manual boot recovery procedure.

include::../_include/encryption_restore_bootmedia.adoc[]

.What's next?
After restoring encryption on the boot media, you need to link:bootmedia-complete-rma.html[return the failed part to NetApp].

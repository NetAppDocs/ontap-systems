= Boot the recovery image on a FAS2820 system using the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
After installing the new boot media device in your FAS2820 system, you can boot the recovery image manually from a USB drive to restore the configuration from the partner node.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure]. If your system is running an earlier version of ONTAP, you must use the manual boot recovery procedure.

.What's next?
After booting the recovery image, you need to link:bootmedia-encryption-restore.html[restore encryption on the boot media].

= Learn about boot media replacement in your FAS2820 system
:icons: font
:imagesdir: ../media/

[.lead]
The boot media in your FAS2820 system stores a primary and secondary set of system boot image files that the system uses when it boots. Depending on your network configuration, you can perform either a nondisruptive or disruptive replacement.

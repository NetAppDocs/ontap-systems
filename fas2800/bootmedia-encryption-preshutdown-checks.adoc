= Check encryption support on your boot media in your FAS2820 system
:icons: font
:imagesdir: ../media/

[.lead]
To ensure data security on your FAS2820 storage system, verify the encryption key support and status on your boot media. Check whether your ONTAP version supports NetApp Volume Encryption (NVE). Before you shut down the controller, check whether the key manager is active.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure]. If your system is running an earlier version of ONTAP, you must use the manual boot recovery process.

== Step 1: Check NVE support and download the correct ONTAP image

Determine whether your ONTAP version supports NetApp Volume Encryption (NVE) so you can download the correct ONTAP image for the boot media replacement.

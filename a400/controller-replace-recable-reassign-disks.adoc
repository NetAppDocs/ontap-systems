= Give back the controller - AFF A400
:icons: font
:imagesdir: ../media/

[.lead]
Return control of storage resources to the replacement controller so your AFF A400 system can resume normal operation. 

Select the tab that matches your encryption configuration. Systems using External Key Manager (EKM) follow the same steps as no encryption. For Onboard Key Manager (OKM), review https://docs.netapp.com/us-en/ontap-cli/security-key-manager-onboard-show-backup.html[security key-manager onboard show-backup] or contact NetApp Support before starting.

.What's next?

After you've transferred the ownership of storage resources back to the replacement controller, you need to link:controller-replace-restore-system-rma.html[complete the controller replacement] procedure.

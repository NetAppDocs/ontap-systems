= Replace the NVDIMM in an AFF A400 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace the NVDIMM in your AFF A400 system when your system registers that the flash lifetime is almost at an end or that the NVDIMM is not healthy. Failure to replace it can cause a system panic.

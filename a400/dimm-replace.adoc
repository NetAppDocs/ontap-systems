= Replace a DIMM in your AFF A400 system to fix memory errors
:icons: font
:imagesdir: ../media/

[.lead]
Replace a DIMM in your AFF A400 system when the storage system encounters excessive correctable (CECC) or uncorrectable memory errors. Such errors can prevent the storage system from booting ONTAP.

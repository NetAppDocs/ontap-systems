= Check encryption support on the boot media in an AFF A400 system
:icons: font
:imagesdir: ../media/

[.lead]
To maintain data security on your AFF A400 storage system, verify the encryption key support and status on your boot media before you shut down the controller. Check whether your ONTAP version supports NetApp Volume Encryption (NVE) and confirm that the key manager is active.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure]. If your system is running an earlier version of ONTAP, you must use the manual boot recovery process.

= Review requirements before replacing the controller in your FAS8300 or FAS8700 system
:icons: font
:imagesdir: ../media/

[.lead]
Before replacing the controller of your FAS8300 or FAS8700 system, verify all other components in the system are functioning properly, ensure you have the correct replacement controller, and save the controller's console output to a text log file.

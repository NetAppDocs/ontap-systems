= Review requirements before replacing your FAS8300 or FAS8700 chassis
:icons: font
:imagesdir: ../media/

[.lead]
Before replacing the chassis in your FAS8300 or FAS8700 system, all other components in the system must be functioning properly; if not, you must contact technical support. This procedure is supported on all ONTAP versions but causes a complete service outage in a two-controller cluster and a partial outage in a multi-node cluster.

* You can use this procedure with all versions of ONTAP supported by your system.
* This procedure is disruptive: a two-controller cluster experiences a complete service outage, and a multi-node cluster experiences a partial outage.

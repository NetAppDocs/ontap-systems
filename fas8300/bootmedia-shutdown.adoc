= Shut down the controller in your FAS8300 or FAS8700 system during the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Shut down the controller in your FAS8300 or FAS8700 storage system to prevent data loss and maintain system stability during the manual boot media recovery process.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure]. If your system is running an earlier version of ONTAP, you must use the manual boot recovery procedure.

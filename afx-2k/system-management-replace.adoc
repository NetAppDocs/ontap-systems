= Replace system management module - AFX 2K
:icons: font
:imagesdir: ../media/

[.lead]
Replace the System Management module in your AFX 2K storage system when it becomes defective or its firmware is corrupted. The replacement process involves shutting down the controller, replacing the failed System Management module, rebooting the controller, updating the license keys, and returning the failed part to NetApp.

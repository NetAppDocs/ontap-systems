= Replace NV12L - AFX 2K
:icons: font
:imagesdir: ../media/

[.lead]
Replace the NV12L in your AFX 2K storage system when the non-volatile memory becomes faulty or requires an upgrade. The replacement process involves shutting down the impaired controller, replacing the NV12L module or the NVRAM DIMM, and returning the failed part to NetApp.

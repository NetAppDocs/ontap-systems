= Replace a DIMM in an AFF A250 system to fix memory errors
:icons: font
:imagesdir: ../media/

[.lead]
Replace a DIMM in your AFF A250 system when the storage system encounters excessive correctable (CECC) or uncorrectable memory errors. Such errors can prevent the storage system from booting ONTAP.

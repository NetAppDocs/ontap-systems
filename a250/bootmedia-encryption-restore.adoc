= Restore encryption on the boot media in an AFF A250 system after the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Restore encryption on the replacement boot media in your AFF A250 system to ensure continued data protection. The replacement process involves verifying key availability, reapplying encryption settings, and confirming secure access to your data.

If your storage system is running ONTAP 9.18.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure]. If your system is running an earlier version of ONTAP, you must use the manual boot recovery procedure.

.What's next?
After restoring encryption on the boot media, link:bootmedia-complete-rma.html[return the failed part to NetApp].

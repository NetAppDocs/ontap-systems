= Replace a fan in an AFF A250 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace a fan module in your AFF A250 system when a fan fails or is not operating efficiently. The replacement process involves shutting down the impaired controller, removing the controller module, replacing the fan, reinstalling the controller module, and returning the failed part to NetApp.

= Replace the boot media in your AFF A150 system
:icons: font
:imagesdir: ../media/

[.lead]
The boot media in your AFF A150 system stores essential firmware and configuration data. The replacement process involves removing the controller module, removing the impaired boot media, installing the replacement boot media, and then transferring the ONTAP image to the replacement boot media using a USB flash drive.

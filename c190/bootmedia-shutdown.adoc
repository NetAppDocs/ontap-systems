= Shut down the controller in your AFF C190 system during the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Shut down the controller on an AFF C190 system after completing encryption checks. This procedure includes taking the controller to the LOADER prompt, capturing boot environmental variables for reference, and preparing the controller for boot media replacement.

The AFF C190 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

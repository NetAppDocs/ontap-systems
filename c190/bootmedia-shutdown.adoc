= Shut down the controller in an AFF C190 system during the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Shut down the controller in your AFF C190 storage system to prevent data loss and maintain system stability during the manual boot media recovery process.

The AFF C190 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

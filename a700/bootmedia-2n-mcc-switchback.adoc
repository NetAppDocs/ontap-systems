= Switch back aggregates in a two-node MetroCluster configuration for your AFF A700 system
:icons: font
:imagesdir: ../media/

[.lead]
After completing the boot media replacement, perform the MetroCluster switchback operation. The AFF A700 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

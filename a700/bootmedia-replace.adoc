= Replace the boot media in your AFF A700 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace the failed boot media on an AFF A700 controller module. This procedure includes removing the controller module from the chassis, physically replacing the boot media component, transferring the boot image to the replacement media using a USB flash drive, and restoring the system to normal operation.

The AFF A700 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

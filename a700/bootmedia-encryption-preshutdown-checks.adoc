= Check encryption key support and status - AFF A700
:icons: font
:imagesdir: ../media/

[.lead]
To ensure data security on your storage system, you need to verify the encryption key support and status on your boot media. The AFF A700 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

Check if your ONTAP version supports NetApp Volume Encryption (NVE), and before you shut down the controller check if the key manager is active.

== Step 1: Check NVE support and download the correct ONTAP image

Determine whether your ONTAP version supports NetApp Volume Encryption (NVE) so you can download the correct ONTAP image for the boot media replacement.

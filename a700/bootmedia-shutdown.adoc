= Shut down the controller in an AFF A700 system during the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Shut down the controller in your AFF A700 storage system to prevent data loss and maintain system stability during the manual boot media recovery process.

The AFF A700 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

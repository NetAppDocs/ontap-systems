= Boot the recovery image on an AFF A700 system
:icons: font
:imagesdir: ../media/

[.lead]
Boot the ONTAP recovery image from the USB drive on an AFF A700 system to restore the boot media. This procedure includes booting from the USB flash drive, restoring the file system, verifying environmental variables, and returning the controller to normal operation, with specific steps that vary depending on whether the system is in a two-node MetroCluster configuration.

The AFF A700 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

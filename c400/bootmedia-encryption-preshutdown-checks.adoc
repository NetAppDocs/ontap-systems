= Check encryption support on your boot media in your AFF C400 storage system
:icons: font
:imagesdir: ../media/

[.lead]
Check encryption support on your boot media in your AFF C400 storage system before shutting down the impaired controller. This includes verifying ONTAP version compatibility with NetApp Volume Encryption (NVE) and confirming the key manager configuration. 

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure].

Determine whether your ONTAP version supports NetApp Volume Encryption (NVE) so you can download the correct ONTAP image for the boot media replacement.

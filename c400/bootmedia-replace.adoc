= Replace the boot media in your AFF C400 storage system using the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Replace the boot media in your AFF C400 storage system by removing the impaired controller module, installing the replacement boot media, and transferring the boot image using a USB flash drive.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure].

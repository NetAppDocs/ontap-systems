= Replace a DIMM in an AFF C400 system to fix memory errors
:icons: font
:imagesdir: ../media/

[.lead]
Replace a DIMM in your AFF C400 storage system when the system encounters excessive correctable ECC errors or an uncorrectable ECC error, which is typically caused by a single DIMM failure.

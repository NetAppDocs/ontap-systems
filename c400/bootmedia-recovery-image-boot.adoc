= Boot the recovery image on your AFF C400 storage system using the manual boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Boot the recovery image on your AFF C400 storage system from a USB drive to restore the configuration from the partner node.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure].

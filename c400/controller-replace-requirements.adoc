= Review requirements before replacing the controller in your AFF C400 storage system
:icons: font
:imagesdir: ../media/

[.lead]
Before replacing the controller of your AFF C400 system, verify all other components in the system are functioning properly, ensure you have the correct replacement controller, and save the controller's console output to a text log file.

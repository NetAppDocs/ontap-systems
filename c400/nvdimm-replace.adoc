= Replace an NVDIMM in your AFF C400 storage system
:icons: font
:imagesdir: ../media/

[.lead]
Replace an NVDIMM in your AFF C400 storage system when the system registers excessive correctable ECC errors or an uncorrectable ECC error, which is typically caused by a single NVDIMM failure.

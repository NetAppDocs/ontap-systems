= Switch back aggregates in a two-node MetroCluster configuration in an AFF C400 system
:icons: font
:imagesdir: ../media/

[.lead]
After completing the boot media replacement in your AFF C400 storage system in a two-node MetroCluster configuration, perform the MetroCluster switchback operation to restore the configuration to its normal operating state.

If your storage system is running ONTAP 9.17.1 or later, use the link:bootmedia-replace-workflow-bmr.html[automated boot recovery procedure].

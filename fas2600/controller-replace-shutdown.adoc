= Shut down the impaired controller in a FAS2600 system
:icons: font
:imagesdir: ../media/

[.lead]
Shut down the impaired controller in your FAS2600 system before replacement by determining its status and, if necessary, taking it over so the healthy controller continues to serve data from the impaired controller storage.

include::../_include/shutdown_no_mcc.adoc[]

. If the system has only one controller module in the chassis, turn off the power supplies, and then unplug the impaired controller's power cords from the power source.

= Shut down the controller in a FAS2600 system during the boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Shut down the controller in your FAS2600 storage system to prevent data loss and maintain system stability during the manual boot media recovery process.

The FAS2600 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

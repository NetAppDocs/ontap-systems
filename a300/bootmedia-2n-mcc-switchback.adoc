= Switch back aggregates in a two-node MetroCluster configuration - AFF A300
:icons: font
:imagesdir: ../media/

[.lead]
After completing the boot media replacement, perform the MetroCluster switchback operation. The AFF A300 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

= Return the failed part to NetApp - AFF A300
:icons: font
:imagesdir: ../media/

[.lead]
Return the failed part to NetApp after replacing the boot media. The AFF A300 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

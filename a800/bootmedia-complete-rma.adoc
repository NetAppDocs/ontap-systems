= Return the failed AFF A800 boot media to NetApp after the manual boot recovery process
:icons: font
:imagesdir: ../media/


[.lead]
After completing the manual boot recovery process for a failed boot media in your AFF A800 system, return the failed part to NetApp. See the https://mysupport.netapp.com/site/info/rma[Part Return and Replacements] page for details.

= Replace or install a mezzanine card in an AFF C250 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace a failed mezzanine card, or install a new one, in an AFF C250 system by removing the cables and any SFP or QSFP modules, replacing the card, and recabling.

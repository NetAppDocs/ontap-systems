= Shut down the controller in your AFF C250 storage system during the automated boot recovery process
:icons: font
:imagesdir: ../media/

[.lead]
Shut down the controller in your AFF C250 storage system to prevent data loss and maintain system stability during the automated boot media recovery process.

The automated boot media recovery process is supported only in ONTAP 9.18.1 and later. If your storage system is running an earlier version of ONTAP, use the link:bootmedia-replace-workflow.html[manual boot recovery procedure].

include::../_include/shutdown_most_frus.adoc[]

.What's next
After you shut down the controller, you link:bootmedia-replace-bmr.html[replace the boot media].

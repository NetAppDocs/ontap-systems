= Replace the controller in an ASA A150 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace the controller in your ASA A150 system when a hardware failure requires it. The replacement process involves removing the impaired controller module, moving the FRU components to the replacement controller, installing the replacement controller module in the chassis, and booting the system to Maintenance mode.

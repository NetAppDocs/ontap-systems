= Replace the caching module in a FAS2700 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace the caching module in your FAS2700 system when your system registers a single AutoSupport (ASUP) message that the module has gone offline. Failure to do so results in performance degradation.

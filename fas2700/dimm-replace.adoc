= Replace a DIMM in your FAS2700 system to fix memory errors
:icons: font
:imagesdir: ../media/

[.lead]
Replace a DIMM in your FAS2700 system when the storage system encounters excessive correctable ECC errors or an uncorrectable ECC error, which is typically caused by a single DIMM failure.

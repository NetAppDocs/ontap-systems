= Boot the recovery image - FAS2700
:icons: font
:imagesdir: ../media/

[.lead]
Boot the ONTAP recovery image from the USB drive on a FAS2700 system to restore the boot media. This procedure includes booting from the USB flash drive, restoring the file system, verifying environmental variables, and returning the controller to normal operation after boot media replacement.

The FAS2700 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

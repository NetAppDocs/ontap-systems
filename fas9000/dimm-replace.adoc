= Replace the DIMM in a FAS9000 system to fix memory errors
:icons: font
:imagesdir: ../media/

[.lead]
Replace a DIMM in a FAS9000 system when the system reports excessive correctable ECC memory errors through Health Monitor alerts, or uncorrectable ECC errors. A failing DIMM can prevent the storage system from booting ONTAP, so replacing it restores stable operation.

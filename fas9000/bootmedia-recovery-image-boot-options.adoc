= Boot the recovery image - FAS9000
:icons: font
:imagesdir: ../media/

[.lead]
The procedure for booting the impaired node from the recovery image depends on whether the system is in a two-node MetroCluster configuration. The FAS9000 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

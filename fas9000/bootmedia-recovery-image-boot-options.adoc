= Boot the recovery image on your FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
After you install the replacement boot media in your FAS9000 system, boot the recovery image from a USB drive. The procedure for booting the impaired controller depends on whether the system is in a two-node MetroCluster configuration. The FAS9000 system supports only manual boot media recovery procedures.

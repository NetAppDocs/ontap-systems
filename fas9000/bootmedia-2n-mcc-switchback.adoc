= Switch back aggregates in a two-node MetroCluster configuration - FAS9000
:icons: font
:imagesdir: ../media/

[.lead]
After completing the boot media replacement, perform the MetroCluster switchback operation. The FAS9000 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

= Hot-swap a caching module in a FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
Hot-swap the caching module in a FAS9000 system. Beginning with ONTAP 9.4, you can hot-swap the NVMe SSD Flash Cache module, located in front of the NVRAM10 module in slot 6, with a caching module of the same capacity from the same or a different supported vendor.

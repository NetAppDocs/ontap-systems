= Replace the NVRAM module or NVRAM DIMMs in a FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace a failed NVRAM module or the DIMMs inside the NVRAM module in a FAS9000 system. Because the system ID is derived from the NVRAM module, replacing the module reassigns the disks belonging to the system to the new system ID.

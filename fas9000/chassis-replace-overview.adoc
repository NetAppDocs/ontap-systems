= Review the requirements for replacing a chassis in a FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
Before replacing the chassis in a FAS9000 system, verify that all other components are functioning properly and that the replacement chassis is the same model as the impaired chassis. The procedure is disruptive, causing a complete service outage in a two-node cluster or a partial outage in a multi-node cluster.

= Learn about boot media replacement in your FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
The boot media stores a primary and secondary set of system (boot image) files that the system uses when it boots. The FAS9000 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

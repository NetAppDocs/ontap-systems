= Learn about boot media replacement in a FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
Learn about boot media replacement in a FAS9000 system. The boot media stores a primary and secondary set of system (boot image) files that the system uses when it boots. The FAS9000 system supports only manual boot media recovery; automated boot media recovery is not supported.

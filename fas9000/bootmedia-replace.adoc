= Replace the boot media in your FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
To replace the boot media, you must remove the impaired controller module, install the replacement boot media, and transfer the boot image to a USB flash drive. The FAS9000 system supports only manual boot media recovery procedures. Automated boot media recovery is not supported.

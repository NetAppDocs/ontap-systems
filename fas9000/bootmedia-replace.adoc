= Replace the boot media in a FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace the boot media in a FAS9000 system by removing the impaired controller module, installing the replacement boot media, and transferring the boot image to a USB flash drive. The FAS9000 system supports only manual boot media recovery; automated boot media recovery is not supported.

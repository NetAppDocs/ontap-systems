= Check encryption support on your boot media in your FAS9000 system
:icons: font
:imagesdir: ../media/

[.lead]
To ensure data security on your storage system, verify the encryption key support and status on your boot media. Check whether your ONTAP version supports NetApp Volume Encryption (NVE), and before you shut down the controller, check whether the key manager is active. The FAS9000 system supports only manual boot media recovery procedures.

= Replace an NVDIMM in your ASA C400 system
:icons: font
:imagesdir: ../media/

[.lead]
Replace an NVDIMM in your ASA C400 system when the storage system encounters excessive correctable ECC errors or uncorrectable ECC errors, which are typically caused by a single NVDIMM failure.

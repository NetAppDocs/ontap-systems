= Replace a DIMM in an ASA C400 system to fix memory errors
:icons: font
:imagesdir: ../media/

[.lead]
Replace a DIMM in your ASA C400 system when the storage system encounters excessive correctable error correction code (ECC) errors or an uncorrectable ECC error, which is typically caused by a single DIMM failure.

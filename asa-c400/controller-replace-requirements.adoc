= Review the requirements for replacing a controller in an ASA C400 system
:icons: font
:imagesdir: ../media/

[.lead]
Before replacing the controller of your ASA C400 system, verify all other components in the system are functioning properly, ensure you have the correct replacement controller, and save the controller's console output to a text log file.
